Escopo

• Desenvolver funcionalidades de um sistema
• Web
• Que armazena dados em um banco relacional

• Cada integrante deve desenvolver
• 2 funcionalidades de complexidade alta ou
• 1 funcionalidade de complexidade média e 2 de complexidade baixa ou
• 4 funcionalidades de complexidade baixa

• Funcionalidade
• Completa
• Não pode ser apenas leitura

Requisitos

• Grupos de 4 a 6 integrantes
• Todos os artefatos (código, documentação, modelos, etc.) do
projeto devem ser publicados no GitHub em um repositório
• Público
• Privado, mas acessível pelo usuário @profsauloaraujo
• Java
• Tecnologias sugeridas
• Spring Boot
• JPA
• Angular ou Vaadin

Requisitos

• Descrição do domínio fazendo uso da linguagem onipresente
• Mapa da história do usuário
• Protótipos de alta fidelidade
• Modelo(s) do(s) subdomínio(s) desenvolvido com o Context
Mapper (arquivo CML)
• Cenários de teste BDD
• Automação dos cenários de teste BDD com o Cucumber

Requisitos

• Adotar os níveis preliminar, estratégico, tático e operacional do
DDD
• Arquitetura limpa

Requisitos

• Adotar 4 ou mais dentre os padrões:
• Iterator
• Decorator
• Observer
• Proxy
• Strategy
• Template method

• Implementar a camada de persistência com mapeamento objeto-
relacional

• Implementar a camada de apresentação web
